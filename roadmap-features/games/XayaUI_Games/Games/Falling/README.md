# Falling blocks: ON HOLD (Xaya's decision)

Not outlined. *Tetris Holding v. Xio Interactive* (D.N.J. 2012) found that a clone copying the game's look infringed its copyright and trade dress (`ARCADE-FEASIBILITY.md` section 4, with sources). Renaming is not enough.

Xaya decides (feasibility question 2):
- **A clearly different design:** different pieces, a different field shape and our own look. It would follow the other games' shape: frame-free rules, keyboard through `Arcade/Keys.lua`, the board through `Arcade/Grid.lua`.
- **Or leave it out.**

This is not legal advice.
