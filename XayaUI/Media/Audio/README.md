# Audio folder

No audio files are included in this repository (licensing: see the top-level README).

Put your own `.ogg` / `.mp3` files anywhere under this folder, then list them in `LocalSounds.lua`
(format: `{ "Label shown in the dropdown", "Interface\\AddOns\\XayaUI\\Media\\Audio\\yourfile.ogg" }`).
New audio files need a full game restart (not `/reload`) before WoW can play them.
`Custom/` is a convenient place for your own sounds.
