# Converted EUI aura rules now carry a display condition (no addon change; issue #294)
Logged 2026-11-03 00:35 UTC. Build in use: 0.5.80, fork: main.

Xaya: "none of your eui exports have conditions to display them". The conversion (parent rule + hidden icon cue per aura) had no Conditions-tab row. Per Cues.lua a rule with no conditions drives its cues from its own trigger, so the cues should have followed the Buff / Aura trigger anyway; what she saw (an empty Conditions tab, and/or nothing displaying) was not confirmed because her saved data could not be read (folder access declined). Change: converter emits one condition per aura (when ref "buff" is true, then cue q1), 95 for the main import (5 groups) and 5 for the HUD import; decoded with the addon's own Profile_Decode (285 and 15 records). Not tested in game. Not done: the groups still import as plain groups (no dynamic container type, spacing, or position; those values are in groups.json); the engine tag is still in the strings. Old imports must be deleted by hand (Recycle Bin); the new Import window puts each import in its own "Imported: ..." folder so they cannot mix.
