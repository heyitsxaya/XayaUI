# Tester: Anti-Magic Shell without duration in combat; engine extended to every aura display (XayaUI 0.5.93 / engine 0.4.0, fork: main)
Logged 2026-11-03 ~02:00 UTC. GitHub issue: #311. Tester Insivius (via Xaya), build 0.5.90: Anti-Magic Shell (48707, Blood) shows no time in combat. Xaya: "extend the engine to literally everything at this point. we don't want anything slipping through".
Cause: the rule is in no group; the engine only drew dynamic groups, so XayaUI's own icon was used, which cannot show a hidden duration in combat.
Change: engine draws every aura display it can show faithfully - dynamic groups (one container each), every other buff rule as a single slot sitting on XayaUI's own icon (same parent, strata, size), "Target Debuff (yours)" rules outside dynamic groups on target / focus (HARMFUL|PLAYER; spell-ID filtering on enemy units is allowed per Blizzard's AuraContainerUtil). Load / talent answers followed live (4 times a second, no allocation unless a member changes). Kept with XayaUI, each named with its reason by /xuiengine: displays that show while an aura is MISSING (the engine would draw them backwards; previously wrong in group mode too), displays that also need a cooldown state or another trigger, target debuffs inside dynamic groups, centred-growth groups, groups kept with /xuiengine off. Edits rebuild automatically (1 s after the last edit, never in combat). Guard: engine addon + Blizzard_AuraContainer CPU; first lean mode (current spec only, /xuiengine full to undo), then off.
New: ns.DisplayFrame (Visual.lua). Module rewritten in sections (classification, containers, groups, singles, live sync, status, guard, events).
Verified offline: aura_display_run 41/41, layout_parity_run 18/18, all other suites; dry run on Xaya's rules unchanged (4 groups, 94 rules, nothing left behind). Unverified in game: single slots, target-debuff slots, live load sync in combat (SetAuraGroupCandidateFilters / SetShown in combat are pcall'd).
Files: XayaUI_CombatEngine/AuraDisplay.lua (rewritten), Visual.lua, USER-GUIDE.md, XayaUI_CombatEngine/README.md, both .toc files, tests/aura_display_run.py, tests/layout_parity_run.py, MANIFEST.md5.
