# Load tab: all options stay visible in every mode (XayaUI 0.5.77, fork: main, issue #287)
Logged 2026-11-02 23:55 UTC.

Xaya: "where did all my load options go?" (Always load ticked, no condition options). Her instruction after I described that: "do not do this, show all options, please". Change: noMatch() now returns false and the Hero Talents group uses it, so every option shows in every mode; a yellow note under the mode choice appears for Always / Never saying the options are kept but not used until Match ALL / ANY is ticked. Evaluation is unchanged (Conditions.lua still returns true for Always and false for Never). USER-GUIDE.md section 3 table updated. Why her rule was on "Always load" is still unknown (default mode is blank; the imports never set it). Verified: Lua syntax only. Not tested in game. Weak point: options that look active but are ignored; the note is the only cue.
