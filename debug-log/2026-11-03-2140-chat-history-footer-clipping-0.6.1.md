# Xaya: Chat history window, text clipped at the bottom of the pane (XayaUI_Chat 0.6.0, fork: main)
Logged 2026-11-03 21:40 UTC. GitHub issue: #331. Xaya (Bug Reporting: Chat): "popout window has text clipping on the bottom of the pane." Screenshot: Chat history window on the Trade tab; the status line ("1 newer message. Click Refresh to show them.") runs into the privacy note on the same row and the start of the note is hidden behind the Live button.
Cause (read from History.lua, matches the screenshot): the note was anchored bottom-right only (no left bound, no width) so it grew leftward under the Refresh and Live buttons; the status line was anchored right of Live with no right bound on the same row; neither could wrap or shorten, so at 540 wide (default) and 400 wide (minimum) they could not fit.
Change (XayaUI_Chat 0.6.1): the footer is two bands. Buttons and status on the upper band; the note under them, left-aligned, bounded on both sides, stopping left of the resize grip, wrapping to two lines when narrow. The scroll area stops above both. The status line is bounded on both sides, does not wrap, and reads "N newer message(s). Click Refresh." The minimum window size is 440x300 (was 400x260); saved sizes are untouched.
Verified offline: tests/chat_run.py footer block (540x380, 440x300, 900x600: scroll above buttons, buttons above note, note inside the window and left of the grip, status right of Live and inside the window, status fits its width); all tests/*_run.py pass. The whole-addon harness shows 1 failure that is identical on unmodified main (C_Texture is nil in the harness stand-in, Options.lua:4481; no API index loaded in this session), so not caused by this change.
Unverified in game: real font widths (the stand-in assumes 6 px per character, wider than the real font), the note wrapping at the minimum width, long-history scroll-to-bottom (not touched).
Needed from Xaya / testers: open the history window with newer messages waiting and check the bottom row at the default size and at the smallest; report any clipping or overlap.
Files: XayaUI_Chat/History.lua, XayaUI_Chat/XayaUI_Chat.toc, tests/chat_run.py, MANIFEST.md5.
