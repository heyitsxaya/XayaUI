# Chat Panel rebuilt from scratch (XayaUI 0.5.90, fork: main)
Logged 2026-11-03-0045 UTC. GitHub issue: #297 (rebuild requested); probe stage was 0.5.82.
Request (Xaya): "rebuild the chat, please", then "just build it and I'll give you feedback when I see it".
Change: the old Chat Reskin / Chat Panels / ElvUI-style chat code is removed (ChatReskin, ChatText, ChatTabs, ChatWidgets, ChatDock, ChatPanels, ChatPanel, ChatTrade). New Chat/*.lua modules reskin Blizzard's own chat in place inside one block: tab row, text, input line INSIDE the pane, optional Chat Bar above or below (Data Panels block engine), collapse arrow, mover and resize, fade, theme option, texture picker, spam filters (repeat suppression, blocked phrases, Ctrl+right-click ignore), clickable links with copy box, history pane, per-tab sounds. The privacy cover was re-homed onto the new pane (covers text and input line; bar and arrow stay visible). Settings start fresh (CueRulesDB.chat2); old chat settings are not read. `/xui chat on|off|reset|move|history|settings`.
Dropped with the old code: the Trade tab option (ChatTrade.lua). Restorable from git history if wanted.
Tests: tests/chat_run.py with tests/chat_world.lua (stand-in frames with real anchor geometry). 100+ checks pass under the stand-in; one real bug found by it (a loop variable assigned in Messages.lua).
Unverified in game (all of it): the real Blizzard frame names and structure assumed (ChatFrameNButtonFrame, ScrollBar, ResizeButton, Background, QuickJoinToastButton as the floating social button, GeneralDockManager anchoring), how the chat looks, fade and collapse against Blizzard's own alpha changes, protected (secret) chat, the privacy cover's layering over the edit box.
How to report: `/xui chat` prints which parts applied or FAILED; `/xui chatprobe` (S0 probe) is still available.
