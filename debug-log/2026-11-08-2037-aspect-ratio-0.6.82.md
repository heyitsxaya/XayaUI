## 1. What was built (XayaUI_Rules_Options/DisplayTab.lua, ns.GroupDisplayArgs)
- `size.aspect`: a toggle, name "Maintain aspect ratio", order 2.5 (after Display height 2, before Zoom / crop edges 3). Tooltip, one
  sentence: "Width and height change together, keeping the proportion they had when you ticked this box."
- Off by default: nothing is stored until the box is ticked; `get` is true only while a proportion is stored.
- Implementation details (her answer left them to the build; invisible to her except where noted):
  - **Where the proportion is stored:** on the group itself, `f.dispAspect` = width / height as the two sliders showed it at the tick
    (the first display's numbers, which the sliders show). nil = off. It sits beside the group's other saved settings (`barStyle`,
    `barStyleForce`, `cWrapN` ...), so it is saved with the group, goes with an exported group (`ns.Share_SnapshotGroup` copies the
    whole group table) and survives a /reload. Like the group's other settings, "Duplicate" (Sidebar.lua `DuplicateFolder`, which
    copies only the rules) does not carry it. Unticking removes it.
  - **Rounding:** the side that follows is rounded to a whole pixel, half up (`math.floor(x + 0.5)`), matching the sliders' step of 1.
    Example: width 51 at 2 : 1 gives height 26 (25.5).
  - **Clamping:** the side that follows is kept within the sliders' 8-512. **Where the clamp breaks the proportion, the clamped value
    is kept** (as she said): at 2 : 1, height 512 gives width 512 (not 1024), so the displays are square there; width 8 gives height 8
    (not 4). The stored proportion is not changed by a clamp, so the next change inside the range gets it back (height 32 gives width 64
    again).
  - The side she moves is written as she set it; both sides are written to every display of the group (the section's normal
    behaviour: a change makes them all the same). Edit-locked rules stay out (unchanged code path, the same `list()`).
- Not changed: a rule's own Display tab, a cue's own Display width / height (Editor.lua 1386-1388), the engine (XayaUI_Rules), the
  sliders' range and step, the "Differs between displays" line.
