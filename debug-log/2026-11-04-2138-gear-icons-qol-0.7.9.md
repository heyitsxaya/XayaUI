## Game API (V2)
The public reference (`docs/reference/api/`) leaves out the old inventory globals (it lists documented functions only;
`GetInventoryItemLink`, already used here, is not in it either). How Blizzard's own UI calls them, read in the live 12.1.5 source
(Gethe/wow-ui-source, live branch, 2026-11-04):
- `Blizzard_UIPanels_Game/Mainline/PaperDollFrame.lua:1695` `GetInventoryItemTexture("player", self:GetID())` (nil = empty slot);
  `:1733` `GetInventoryItemQuality("player", self:GetID())`; `:1689` `HandleModifiedItemClick(GetInventoryItemLink("player", id),
  itemLocation)` for the modified click.
- `Blizzard_FrameXMLUtil/ItemUtil.lua:391` (`ItemUtil.DisplayEquipSlotTooltip`): `tooltip:SetInventoryItem("player", equipSlot)`.
- `C_Item.GetItemQualityColor(quality: ItemQuality)` → `colorRGBR, colorRGBG, colorRGBB, qualityString` ·
  SecretArguments=AllowedWhenUntainted (`namespaces.md:2789`).
- All reads through `R()` / `N()`: a secret texture or quality is not used (question mark, plain border). The hover is pcall'd and
  falls back to the item link (`SetHyperlink`).
