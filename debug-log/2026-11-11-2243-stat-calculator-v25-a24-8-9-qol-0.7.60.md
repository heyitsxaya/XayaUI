## 1. What was built
- **statcalc** (`XayaUI_Bonus/StatCalculator.lua`).
  - A24 #9 "Widen the panel": while the Stats tab draws the Stat Weights pane unfolded, the panel is drawn at least as wide as the six
    columns' widest words need (WeightSpec / WeightsContentNeed: FitCols' "min" level plus five gutters), docked or on its own, never

  - A24 #8 minimap row: the launcher's available() returns PanelAvailable(), so the row is left out of a list opened in combat. Core
    reads available() each time the list opens (XayaUI/MinimapButton.lua:48-50, :113); nothing polls.
  - Read-only tooling: statCalc service Window(), ns.StatCalc_Drawn().width, ns.StatCalc_WidthNeedComputes.
  - Walkthroughs: `QAWalks-influences.lua` ("statcalc-influences", E1z242) step 2 CheckNarrow, new step 4 CheckGrip;

## 4. V25 six criteria
1. Runtime cost: the width need is measured only on a draw (events, inputs, the panel's buttons; never per frame) and only when its
   signature changes; WeightCols still measures the pane on each draw as before (unchanged). The minimap row's available() runs once per
   list open. The Esc entry is one table insert at Build. Slot rows: same number of font strings as before; no new loop, event, hook or
   timer. Placement() and Window() run only when a walkthrough asks. Nothing runs while the features are off (V14).
2. Structure: one need routine shared with WeightCols (WeightSpec); the width is applied in one place (ApplyWidth); tab placement is the
   same formula in Build and ApplyWidth; the slot layout has one placement path (the Style branches removed).
3. Maintainability: comments name A24 #8 / #9; the three-line title cases are listed exactly in tests/char_stat_round_run.py THREE_LINES.
4. Game safety: no Blizzard function replaced, no protected call, no new hook; UISpecialFrames is the game's documented Esc list used
   the same way by every XayaUI window. Positions and sizes whole pixels (V27): widths floored, tab x / width whole (tested).
5. UX: nothing cut in Stat Weights at the stand-in widths; Esc behaves as for the game's windows; open UX choices listed in 6.
6. Player control: no keyboard, focus or screen taken; in combat the panel and its minimap row stay hidden ("Hide silently", V26);
   a Change box lets go on the first Esc (V29).
V26: no window or command added; the Stat Calculator stays locked in combat.
