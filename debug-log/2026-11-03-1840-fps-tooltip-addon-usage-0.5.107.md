# Xaya: hovering FPS should show which addons use what memory / CPU, like the addon list (XayaUI 0.5.107, fork: main)
Logged 2026-11-03 ~18:40 UTC. Feature request (screenshots: the Chat Bar "FPS: 34 MS: 40" tooltip showing only Latency Home / World, and Blizzard's Addon List "AddOn Usage: Current CPU 3%, Average CPU 7%, Peak CPU 54%").
Change: the FPS, Latency and FPS-and-latency blocks (Chat Bar, and the same three types on screen Data Panels) now add an "AddOn usage" section under their tooltip: current / average / peak CPU as a share of the whole application (same C_AddOnProfiler metrics and percent format the Addon List uses), top 8 addons by recent CPU with each one's session average, and memory in total plus the top 8 addons (GetAddOnMemoryUsage, KB / MB). Redraws once a second while the mouse stays on the block; not drawn in combat (the Chat Bar already skipped tooltips in combat; Data Panels follow their own "block hover in combat" option). Memory is re-read at most every 15 s (the Addon List does the same; the call is costly). If the profiler or the memory API is missing the section says so or leaves that part out; an error inside it prints one red line in the tooltip and never breaks the block.
Source for the API names and formulas: Blizzard's own Addon List and Performance Bar code (Blizzard_AddOnList/AddonList.lua, Blizzard_PerformanceBar/PerformanceBar.lua, Blizzard_APIDocumentationGenerated/AddOnProfilerDocumentation.lua, build 12.1.5.70688).
Verified offline: tests/usage_run.py 12/12 (stand-in profiler and memory APIs: percent math, sorting, zero-memory addons left out, 15 s memory throttle, profiler missing, secret values skipped, throwing API contained); Chat/Bar.lua, DataPanels.lua, DataBlocks.lua compile.
Unverified in game: how the tooltip looks at 8 + 8 rows, that C_AddOnProfiler.GetTopKAddOnsForMetric returns addOnName in the live client as in the documentation, and that the numbers match the Addon List (they use the same calls). Not changed: no option to turn the section off or to change the row count (8) yet; the Currencies / other blocks have no usage section.
Files: DataBlocks.lua, Chat/Bar.lua, DataPanels.lua, USER-GUIDE.md (12.10), tests/usage_run.py, tests/usage_check.lua.
