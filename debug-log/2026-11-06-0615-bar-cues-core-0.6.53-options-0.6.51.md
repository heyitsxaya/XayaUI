## Game facts used (V2; docs/reference/api, 12.1.5, quoted)
- `SetTimerDuration(duration: LuaDurationObject, interpolation: StatusBarInterpolation = "Immediate", direction: StatusBarTimerDirection = "ElapsedTime") · SecretArguments=AllowedWhenUntainted · SimpleStatusBarAPI`
- `SetStatusBarColor(colorR: number, colorG: number, colorB: number, a: SingleColorValue?) · SecretArguments=AllowedWhenTainted, SecretArgumentsAddAspect=[SecretAspect.VertexColor, SecretAspect.Alpha] · SimpleStatusBarAPI`
- `C_TooltipInfo.GetSpellByID(spellID: SpellIdentifier, isPet: bool?, showSubtext: bool?, dontOverride: bool?, difficultyID: number?, isLink: bool?) → data: TooltipData · MayReturnNothing, SecretArguments=AllowedWhenTainted`
- `C_TooltipInfo.GetUnitAuraByAuraInstanceID(unitToken: UnitTokenRestrictedForAddOns, auraInstanceID: number, filter: AuraFilters?) → data: TooltipData · MayReturnNothing, RequiresUnitAuraAccess, SecretArguments=AllowedWhenUntainted, SecretWhenUnitAuraRestricted`
- `C_UnitAuras.GetAuraDispelTypeColor(auraInstanceUnit: UnitToken, auraInstanceID: number, curve: LuaColorCurveObject) → dispelTypeColor: colorRGBA (ColorMixin) · RequiresUnitAuraAccess, RequiresValidUnitAuraInstance, SecretArguments=AllowedWhenUntainted, SecretWhenCurveSecret, SecretWhenUnitAuraRestricted`
- `C_Spell.GetSpellCooldownDuration(spellIdentifier: SpellIdentifier, ignoreGCD: bool = false) → duration: LuaDurationObject · MayReturnNothing, SecretArguments=AllowedWhenTainted`
  and `C_Spell.GetSpellChargeDuration(spellIdentifier: SpellIdentifier) → duration: LuaDurationObject · MayReturnNothing, SecretArguments=AllowedWhenTainted` (used through the existing Visual.lua CooldownDuration).
- **No call gives a spell's school.** Searched api.json for "school": only `C_Spell.GetSchoolString(schoolMask)` (needs a mask),
  `GetSpellBonusDamage(school)`, garrison `AutoCombatSpellInfo.schoolMask` / `AutoMissionEvent.schoolMask`, and `lockoutSchool`. Hence
  the tooltip read Xaya chose.
- Blizzard 12.1.5 UI source (Gethe/wow-ui-source 297d7aa "12.1.5 (70783)", read in the session scratchpad, nothing copied):
  - `Blizzard_AuraContainer/Blizzard_CustomAuraButton.lua`: `SetDurationBar(statusBar, options)` (status bar driven by
    `SetTimerDuration`), `SetApplicationBar(statusBar, options)` (`SetMinMaxValues(minApplications, max(maxApplications, 1))`, value =
    `auraData.applications`), `SetSpellName(fontString)`, `AddDispelTypeTexture(texture, options)` with `showAlways`, style
    `PreserveAsset` (`AuraUtil.SetAuraBorderColor`) and `customDispelColorMap` keyed by `auraData.dispelName or "None"`.
  - `Blizzard_AuraContainerUtil.lua` ValidateInboundScriptObject: an inbound object must be the button "or a direct or indirect
    descendant of owner", so the bar's fill texture (child of our StatusBar, child of the button) is accepted.
  - Default colours: `Blizzard_FrameXMLUtil/AuraUtil.lua` `AuraUtil.GetAuraBorderColor(dispelType)` (Magic, Curse, Disease, Poison,
    Bleed, None); `Blizzard_CombatLogBase/Mainline/CombatLogColors.lua` `COMBATLOG_DEFAULT_COLORS.schoolColoring[Enum.Damageclass.Mask*]`
    (Blizzard_CombatLogBase is LoadOnDemand). Both are READ AT RUN TIME; no colour value is in our files.

## Decisions (mine; each waits on Xaya, REQUEST-LOG S7-5)
1. Parts on by default: icon at the left, spark on (white, 90 % opacity, 12 px), name on (left, 12), time on (right, 12); count off.
2. A sixth Tracks choice, **Automatic** (the aura when the rule watches one, else the cooldown), is the default.
3. Preset numbers (hue kept): Neon saturation x 1.35 + 0.15, brightness 1; Pastel saturation x 0.45, brightness x 0.35 + 0.65;
   Muted / Dark saturation x 0.6, brightness x 0.7. The fixed blue is not restyled ("Fixed blue").
4. Bar Colours is one global setting on Settings > UI Options (all bars), not per cue.
5. Types: the five dispel types the game has a colour for (Magic, Curse, Disease, Poison, Bleed) and seven schools.
6. Textures: Flat (default), Blizzard, Raid frame (paths from XayaUI's own shelved Bars.lua list), every LibSharedMedia status bar, own file.
7. New Rule > Progress Bar makes a Bar-cue rule; Smart Categories > Progress Bars lists them.
8. A ready cooldown bar shows no time remaining (empty; full when Fill up is ticked). A stacks / charges bar fills by the count and
   ignores Fill up.
9. Tooltip words: the dispel word only in the first line's right-hand text; schools only as "<word> damage" in later lines; English.
10. The Hue / Saturation sliders proposed in round 2 were not built (her round-3 answer put Custom pickers in their place).
