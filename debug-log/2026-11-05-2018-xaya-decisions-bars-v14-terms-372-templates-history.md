## Checked in the code (main 19321e7), for the follow-up work
- Disabled rules: `Engine.lua` `StepRule` calls `StepDisabled` for a disabled rule every step, then `StepPreview` for every rule.
  The preview is how a rule being edited shows on screen, so a disabled rule open in the editor still needs it (to keep).
- No display uses a secure template (`grep` for Secure*Template in `XayaUI/` and `XayaUI/Combat/`: none), so building a rule's frames
  when it is switched on in combat is not blocked by the game (INFERENCE: plain frames can be created in combat; not tested here).
- Chat history (`XayaUI_Chat/History.lua`): the pane opens on "All" (`tabKey = "ALL"` at load, line 24, kept between opens; reset to
  "All" when the chosen window is gone, lines 221-225). Tab buttons: All, then each chat window that `GetChatWindowInfo` reports
  shown or docked (or the main window), then Console (`Windows()` 56-68, `RebuildTabButtons()` 203-226). Messages are sorted to a
  window by its message groups or channels (`C.Shows`, 38-54).
  INFERENCE (not checked in game): a whisper window the game opens (`FCF_OpenTemporaryWindow`, whisperMode "popout" / "popout_and_inline")
  gets no button today, because `GetChatWindowInfo` is not known to answer for those windows, and if it did get one, it would show
  every whisper, not one conversation, since `C.Shows` matches by group and not by the person.
  XayaUI_Chat has no whisper-tab setting of its own today (`Options.lua`: only whisper sounds and the spam filter mention whispers).
- Group origin: nothing in `XayaUI/` or `XayaUI_Options/` records who or what made a group (`grep` for creator / author / createdBy /
  origin: none), so "original character / source of creation" is new saved data; groups made before it can only show "not recorded".
- Templates: no rule template system exists. Triggers already read "alive" (`Triggers.lua:902`, `UnitIsDeadOrGhost("player")`).
  Durability is not read anywhere today.
