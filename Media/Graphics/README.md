# Graphics folder

No graphics are included in this repository (much of the art is extracted Blizzard UI art).
Put your own `.tga` files here (32-bit, width/height powers of two, e.g. 64/128/256/512) and list them in `LocalGraphics.lua`
(format: `{ "Label", "Interface\\AddOns\\XayaUI\\Media\\Graphics\\file.tga", width, height }`).
New files need a full game restart.
